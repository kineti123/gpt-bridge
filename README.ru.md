# gpt-bridge

[English](README.md) | Русский

MCP-сервер, который позволяет Claude Code передавать задачи Codex (моделям OpenAI GPT) через вашу подписку ChatGPT на macOS.

[![Платформа: macOS](https://img.shields.io/badge/platform-macOS-lightgrey.svg)](#требования)
[![Python 3](https://img.shields.io/badge/python-3-3776AB.svg)](#требования)

> **Отказ от ответственности.** Проект не связан с OpenAI или Anthropic, не одобрен и не поддерживается ими. Он запускает Codex CLI, который входит в ChatGPT.app, и общается с ним по протоколу `codex app-server`. Все вызовы расходуют лимит вашего плана ChatGPT. Перед использованием прочитайте условия OpenAI. Вы сами отвечаете за то, как используете проект.

## Зачем нужен gpt-bridge

Claude Code и Codex хорошо справляются с разными задачами. Если у вас есть подписка ChatGPT, в неё уже входит доступ к Codex. gpt-bridge позволяет Claude Code поручать ему задачи: задавать вопросы, передавать большие задачи агенту, просить прочитать изображения, создавать изображения или проверять код. Ключ API OpenAI не нужен.

## Как это работает

```
Claude Code ──MCP (stdio)──> server.py ──JSON-RPC (stdio)──> codex app-server ──> ваш аккаунт ChatGPT
```

- `server.py` — MCP-сервер с транспортом stdio. Он использует только стандартную библиотеку Python.
- Для каждого вызова инструмента запускается отдельный процесс `codex app-server`. После выполнения вызова он завершается. Постоянного процесса и фонового опроса нет.
- Вход, токены и сетевые запросы к OpenAI обрабатывает сам Codex CLI. Мост не читает и не сохраняет ваши учётные данные.
- Фоновые задачи (`background: true`) запускаются отдельным процессом `server.py --job <id>`. Процесс завершается вместе с задачей и показывает уведомление macOS.

## Требования

- macOS. В коде используются `fcntl`, `osascript` и путь к ChatGPT.app.
- ChatGPT.app с выполненным входом и встроенным Codex CLI по адресу `/Applications/ChatGPT.app/Contents/Resources/codex-cli/bin/codex`. Можно указать другой бинарный файл `codex` через переменную окружения `GPT_BRIDGE_CODEX` или добавить `codex` в `PATH`.
- Python 3.
- Claude Code.

## Быстрый запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/<owner>/gpt-bridge.git /path/to/gpt-bridge
   ```
2. Запустите самопроверку. Сначала она проверит код без сети, затем один раз запустит `codex app-server`, чтобы прочитать ваш план. Использование моделей не расходуется.
   ```bash
   python3 /path/to/gpt-bridge/server.py --selftest
   ```
3. Проверьте план, расход лимита и доступные модели:
   ```bash
   python3 /path/to/gpt-bridge/server.py --call gpt_status '{}'
   ```
4. Зарегистрируйте сервер в Claude Code:
   ```bash
   claude mcp add gpt-bridge -s user -- python3 /path/to/gpt-bridge/server.py
   ```
5. При желании добавьте правила маршрутизации, чтобы Claude Code понимал, когда звать Codex:
   ```bash
   mkdir -p /path/to/gpt-bridge/state && cp /path/to/gpt-bridge/examples/rules.md /path/to/gpt-bridge/state/rules.md
   ```

После этого попросите Claude Code обычными словами, например: «попроси Codex проверить этот diff».

Названия моделей в `DEFAULTS` (`gpt-6.1-terra`, `gpt-6.1-sol`) доступны в аккаунте автора. Запустите `gpt_status` и измените их в `server.py`, если в вашем аккаунте есть другие модели.

## Навыки для Claude Code

MCP-сервер даёт Claude Code инструменты, а навыки в `skills/` учат пользоваться ими с умом. Claude Code подгружает навык, только когда задача подходит под его описание.

| Навык | О чём он |
|---|---|
| `codex-route` | Когда отдавать задачу Codex, а когда делать самому; какой инструмент и модель подходят к задаче; формат брифа; как принимать результат; что делать, если Codex на паузе. |
| `codex-helpers` | Когда звать Codex по своей инициативе: свежие данные из интернета, картинки, второе мнение, сайты, которые не открываются у Claude; как делить большой ресёрч между агентами Claude и Codex. |

Установка для вашего пользователя:

```bash
mkdir -p ~/.claude/skills && cp -R /path/to/gpt-bridge/skills/* ~/.claude/skills/
```

По желанию правила маршрутизации можно подгружать в начале каждой сессии, а не только когда сработал навык. Добавьте содержимое `examples/session-start-hook.json` в `~/.claude/settings.json`. Хук выводит текст `codex-route/SKILL.md` в контекст сессии.

Навыки, `examples/rules.md` и хук частично повторяют друг друга намеренно. `rules.md` короткий и всегда передаётся как инструкции сервера, а подробности лежат в навыках. Подстройте их под свою работу и под модели, доступные в вашем аккаунте. Сами навыки написаны на английском.

## Инструменты

| Инструмент | Что делает | Расходует лимит моделей |
|---|---|---|
| `gpt_ask` | Короткий запрос к Codex: без плагинов, только чтение. Принимает локальные изображения. Можно включить веб-поиск. | да |
| `gpt_agent` | Полноценный агент Codex в папке задачи (параметр `cwd` обязателен): файлы, команды, плагины, субагенты. По умолчанию полный доступ. | да |
| `gpt_computer_use` | Codex управляет приложениями на этом Маке через OpenAI Computer Use. Экран должен быть разблокирован. | да |
| `gpt_search` | Поиск в интернете или открытие одной страницы. Возвращает источники со ссылками и короткими выдержками. | да |
| `gpt_image` | Создание или редактирование изображений. Файлы копируются в `out_dir` (по умолчанию `images/`). | да |
| `gpt_review` | Проверка незакоммиченных изменений или diff относительно ветки `base`. | да |
| `gpt_connector_list` | Список инструментов коннекторов и MCP на стороне ChatGPT. | нет |
| `gpt_connector_call` | Прямой вызов инструмента коннектора без модели. | нет |
| `gpt_apps` | Подключённые приложения ChatGPT или поиск плагина в каталоге по `query`. | нет |
| `gpt_plugin_install` | Установка плагина Codex (`codex plugin add`). | нет |
| `gpt_threads` | Список, поиск или чтение диалогов Codex. | нет |
| `gpt_jobs` | Список фоновых задач, чтение результата или отмена задачи. | нет |
| `codex_rpc` | Вызов разрешённого метода `app-server` (см. ограничения ниже). | нет, кроме `thread/compact/start` |
| `codex_cli` | Запуск разрешённой команды Codex CLI: `apply`, `archive`, `cloud`, `debug`, `doctor`, `features`, `mcp`, `plugin`, `queue`, `unarchive`. | зависит от команды |
| `gpt_status` | План, расход лимита, время сброса, режим, настройки по умолчанию, журнал за сегодня и модели. | нет |

Общие параметры:

- Инструменты, расходующие лимит модели, принимают `model`, `effort` и `strict_model`.
- Для `gpt_ask`, `gpt_agent`, `gpt_computer_use`, `gpt_image` и `gpt_review` можно задать `background: true`. Вызов сразу вернёт `job_id`. Результат можно получить через `gpt_jobs`.
- `thread_id` продолжает существующий диалог, в том числе начатый в приложении ChatGPT.
- Если ответ длиннее `max_chars` (по умолчанию 30000 символов), инструмент обрежет ответ (в ответе будет пометка «ANSWER CUT» с объёмом недостающего). Полный текст сохранится в `state/results/`.

Модель и усилие по умолчанию для каждого инструмента (`DEFAULTS` в `server.py`):

| Инструменты | Модель | Усилие |
|---|---|---|
| `gpt_ask`, `gpt_search`, `gpt_image` | `gpt-6.1-terra` | medium |
| `gpt_agent`, `gpt_computer_use` | `gpt-6.1-terra` | high |
| `gpt_review` | `gpt-6.1-sol` | high |

## Маршрутизация и лимиты

Claude Code решает, какие задачи передавать Codex. Мост добавляет ограничения:

- **Обычный режим.** Используются запрошенные значения модели и усилия либо значения по умолчанию.
- **Экономный режим.** Включается при расходе от 70% за 5-часовое окно или от 60% за неделю: Sol и Astra заменяются на Terra, а усилие снижается на одну ступень (`ultra`, `max`, `xhigh` до `high`; `high` до `medium`).
- **Стоп-режим.** Включается при расходе от 90% за 5 часов или от 85% за неделю: для всех моделей, кроме Luna, выбирается Terra, а усилие становится `medium`, если оно не было `low`.
- **`strict_model: true`** отключает изменения модели и усилия для этого вызова.
- **Выключатель.** Пока существует файл `state/codex_off`, все инструменты, расходующие лимит модели, отказываются запускаться. Удалите файл, чтобы включить их снова.
- **Журнал.** Каждый вызов модели добавляет строку в `state/delegations.jsonl`: время, инструмент, модель, усилие, режим, ID диалога, статус, длительность, число токенов, примерная стоимость в кредитах, расход до и после, длина ответа. Запросы и ответы в журнал не записываются.
- **Ограничение частоты** (`LIMITS`, `MAX_PARALLEL`) действует на все процессы моста: не более 12 запусков Codex в минуту, 4 процессов Codex одновременно и 60 прямых вызовов коннекторов в час.
- **Исчерпанный лимит.** Когда окно расхода доходит до 100% (или сервер сообщает, что лимит достигнут, или ход падает с ошибкой про usage limit), мост запоминает время сброса и сразу отказывает инструментам с моделью, не запуская Codex. После сброса он включается сам. `gpt_status`, `gpt_jobs` и `gpt_threads` продолжают работать. Если окно не названо или время сброса неизвестно, мост ждёт 30 минут и проверяет снова. Кредиты на аккаунте означают, что лимит не исчерпан. Снять запрет вручную: `python3 server.py --unblock`.
- **Пауза.** Если в ошибке есть Cloudflare, HTTP 429, `too many requests` или `unusual activity`, мост останавливает запросы на 15 минут. Чтобы снять паузу раньше, удалите `state/limits.json`.
- В процессах Codex, запущенных мостом, собственный MCP-сервер моста отключён. Поэтому Codex не сможет зациклить вызовы Codex.

Пороговые значения заданы самим мостом, это не лимиты OpenAI. Оценка кредитов считается по постоянным ценам в `CREDITS` и может отличаться от фактической стоимости.

## Файлы в `state/`

Мост при необходимости создаёт папку `state/` рядом с `server.py`. Она добавлена в `.gitignore` и её нельзя отправлять в репозиторий.

| Файл | Назначение |
|---|---|
| `state/rules.md` | Необязательные правила маршрутизации, которые передаются Claude Code в инструкциях MCP-сервера. Пример: `examples/rules.md`. |
| `state/policy.json` | Необязательные переопределения порогов, например `{"economy_5h": 70, "economy_week": 60, "stop_5h": 90, "stop_week": 85}`. |
| `state/codex_off` | Необязательный выключатель: создайте пустой файл, чтобы остановить вызовы моделей. |
| `state/delegations.jsonl` | Журнал вызовов моделей. |
| `state/results/` | Полные тексты длинных ответов. |
| `state/limits.json`, `*.lock` | Состояние общих ограничений частоты, время исчерпанного лимита (`exhausted_until`) и файловые блокировки. |

Рядом с `server.py` также создаются две папки, которые игнорируются Git: `jobs/` (файлы фоновых задач, включая их аргументы и результаты) и `images/` (папка по умолчанию для результатов `gpt_image`).

## Безопасность и конфиденциальность

Что работает локально:

- `server.py` и `codex app-server` работают на вашем Маке. Мост отправляет данные локальному процессу Codex. Затем Codex связывается с OpenAI обычным способом.

Чего мост не делает:

- Не читает, не копирует и не сохраняет токены ChatGPT, пароли или ключи API.
- Блокирует методы `app-server`, которые меняют вход в аккаунт, тратят деньги, публикуют данные или удаляют диалоги (`BLOCKED_RPC`): `account/login`, `account/logout`, `account/gatewayOAuth`, `account/rateLimitResetCredit`, `account/sendAddCreditsNudgeEmail`, `app/list`, `feedback/upload`, `plugin/share`, `thread/delete`. Ходы запускаются только через выделенные инструменты.
- Блокирует инструменты коннекторов с префиксом `safety_settings.` (родительский контроль).
- Разрешает в `codex_cli` только перечисленные выше подкоманды. `exec`, `login` и `logout` запрещены.
- Отключает создание воспоминаний Codex для задач моста и сам MCP-сервер (`gpt-bridge`) во вложенных запусках. Чтобы отключить другие MCP-серверы во вложенных задачах, добавьте их в `BASE_CONFIG` в `server.py`.

Что важно учитывать:

- **`gpt_agent` и `gpt_computer_use` работают с полным доступом** (песочница `danger-full-access`) и автоматически одобряют запросы коннекторов. Codex может читать и менять доступные вашему пользователю файлы, запускать команды и управлять приложениями. Если полный доступ не нужен, задайте `sandbox: "read-only"` или `"workspace-write"` для `gpt_agent`.
- По умолчанию `BLOCKED_APPS` пуст. Поэтому Computer Use может управлять любым приложением. Чтобы заблокировать приложения, добавьте их имена, например `("keychain", "1password")`.
- Модели передаётся указание не выполнять инструкции из изображений, веб-страниц и файлов. Это снижает риск prompt injection, но не устраняет его полностью.
- В `state/`, `jobs/` и `images/` могут храниться ваши запросы, ответы и созданные файлы. Не добавляйте их в Git и не публикуйте в issues.

## Известные ограничения

- Поддерживается только macOS.
- Протокол `codex app-server` экспериментальный и может измениться после обновления ChatGPT. Получить актуальную схему можно так:
  ```bash
  codex app-server generate-json-schema --out /path/to/codex-schema
  ```
- Для `gpt_image` нужен платный план. На бесплатном плане вызов завершается без обращения к модели (можно попробовать с `force: true`).
- Для `gpt_computer_use` экран должен быть разблокирован, а macOS должна выдать запрошенные разрешения.
- Codex может задать уточняющий вопрос. Мост не может ответить на него в рамках того же вызова: отправьте новый вызов с тем же `thread_id`.
- Значения кредитов в журнале и `gpt_status` — оценки.

## Решение проблем

| Сообщение или симптом | Что делать |
|---|---|
| `Codex not found` | Установите ChatGPT.app в `/Applications`, добавьте `codex` в `PATH` или задайте `GPT_BRIDGE_CODEX`. |
| Мост приостановлен до указанного времени | OpenAI или Cloudflare отклонил запрос. Подождите или удалите `state/limits.json`. |
| `ChatGPT usage limit is used up until ...` | Окно расхода по вашему тарифу исчерпано. После сброса мост включится сам. Чтобы снять запрет раньше, вызовите `gpt_status` (он снимает запрет, если окно реально сбросилось) или `python3 server.py --unblock`. |
| Достигнут лимит частоты моста | За минуту запущено больше 12 процессов Codex или за час сделано больше 60 вызовов коннекторов. Подождите и попробуйте снова. |
| Уже запущено 4 процесса Codex | Подождите или отмените фоновую задачу через `gpt_jobs` с параметром `cancel: true`. |
| Codex выключен | Удалите `state/codex_off`. |
| `gpt_agent` просит указать `cwd` | Передайте существующую папку в параметре `cwd`. |
| Вызов завершился по тайм-ауту | Продолжите его с тем же `thread_id`. Для долгих задач увеличьте `timeout_sec`. |
| Перестал работать `gpt_search` | Проверьте, что `thread/start` по-прежнему принимает `ephemeral`, а `web_search="live"` включает поиск в вашей версии Codex. |

## Частые вопросы

**Нужен ли ключ API OpenAI?**

Нет. Мост использует Codex CLI из ChatGPT.app, который работает с вашим аккаунтом ChatGPT.

**Нужно ли за это отдельно платить?**

Мост сам не списывает деньги. Вызовы моделей расходуют лимиты вашего плана ChatGPT. Платные методы `app-server` заблокированы.

**Работает ли он на Linux или Windows?**

Не без доработок. Мост зависит от `fcntl`, `osascript` и пути к ChatGPT.app.

**Можно ли использовать мост без Claude Code?**

Да, для одиночных вызовов: `python3 server.py --call <tool> '<json>'`. Это также стандартный MCP-сервер с транспортом stdio, поэтому могут подойти и другие MCP-клиенты, но проверялся только Claude Code.

**Где хранятся диалоги?**

Диалоги Codex хранятся средствами Codex и вашего аккаунта ChatGPT. Мост сохраняет только локальные файлы из раздела `state/`.
